# 主要步骤
1. 获取源码
2. 配置qemu
3. 配置调试环境
## 获取源码
官方获取地址：http://www.oldlinux.org/Linux.old/Linux-0.11/sources/system/linux-0.11.tar.Z
Linux 0.11 因为很多古老工具链的缺失，以及一些过时的文件格式比如 a.out，导致成功编译并运行它十分困难
建议使用https://github.com/yuan-xy/Linux-0.11的源码（即本项目）
## 安装qemu
```shell
// 安装
apt-get install qemu-system
// 验证安装完成
qemu-system-x86_64 --version
```
## 配置调试环境
```shell
# 1. 编译为可执行文件
make
# 2. 运行
make start // 非调试模式运行
make debug // 调试模式运行
# 3. 调试
# (执行 make debug后，在新窗口进行)
gdb tools/system
target remote :1234
# 4. 正常的gdb命令
```
### vscode远程调试
launch.json添加如下配置
```json
{
    "version": "0.2.0",
    "configurations": [
        {
            "name": "linux-qemu-gdb",
            "type": "cppdbg",
            "request": "launch",
            "program": "${workspaceFolder}/tools/system",
            "miDebuggerServerAddress": "127.0.0.1:1234",
            "args": [],
            "stopAtEntry": true,
            "cwd": "${workspaceFolder}",
            "environment": [],
            "externalConsole": false,
            "MIMode": "gdb",
            "setupCommands": [
                {
                    "text": "set arch i386:x86-64", // 设置体系结构，必须添加
                    "description": "run target",
                    "ignoreFailures": false
                },
                {
                    "description": "为 gdb 启用整齐打印",
                    "text": "-enable-pretty-printing",
                    "ignoreFailures": true
                },
            ],
        }
    ]
}
```
添加"set arch i386:x86-64"配置原因：
> https://zhuanlan.zhihu.com/p/504996444
> https://wiki.osdev.org/QEMU_and_GDB_in_long_mode 三种解决方式
> https://stackoverflow.com/questions/48620622/how-to-solve-qemu-gdb-debug-error-remote-g-packet-reply-is-too-long
> https://blog.csdn.net/weixin_35834894/article/details/124901758

编译 的是64 位模式的内核代码，但是运行是在 32 位保护模式下。64 位代码将无法在该环境中正常调试
因此在运行gdb时需要添加参数`set arch i386:x86-64`
